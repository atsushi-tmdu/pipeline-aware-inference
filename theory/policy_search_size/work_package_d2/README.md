# Work Package D2

Work Package D2 studies fixed-threshold two-bank inference when candidate quantiles and the activation trigger are estimated from the same complete reference bank.

## Files

- `D2_THEORY_MEMO.md`: theoretical derivation.
- `d2_core.py`: regular D2 estimator and independent benchmark.
- `D2_RUNTIME_PREFLIGHT.py`: runtime-only preflight.
- `D2_NUMERICAL_PROTOCOL.md`: locked scientific numerical-validation plan.
- `d2_validation_core.py`: DGP generation and deterministic benchmark calculations.
- `d2_validate.py`: smoke and scientific validation engine.
- `D2_NUMERICAL_CONFIG*.json`: smoke and full configurations.

See `README_NUMERICAL.md` for commands.
