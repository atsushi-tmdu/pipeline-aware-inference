# D8-A Rate-Aware Stopping Amendment V2 Superseded

The uncommitted V2 proposal divided Monte Carlo standard error by the
\(B^{-1}\), \(n^{-1}\), or \(B^{-1}+n^{-1}\) asymptotic bias rate.

Engineering-only output showed that this rule was incompatible with the
prelocked replicate ceilings. For example, diagnostic evaluation-only TESS
outputs implied required replicate counts in the millions.

V2 was therefore rejected before runner lock and before scientific
execution.

The rate-aware scales remain valid and locked for final MCSE-adjusted
acceptance residuals. They are not used for sequential stopping.

V2 is superseded by
`TESS_D8A_PROSPECTIVE_NATURAL_SCALE_PRECISION_CONTRACT_AMENDMENT_V3`.
