# D8-A Studentized-Precision Amendment V1 Superseded

The uncommitted V1 proposal defined

\[
\operatorname{MCSE}/\widehat{\operatorname{SD}}
=
R^{-1/2}.
\]

That rule was rejected before runner lock and before scientific execution
because, outside zero-variance outputs, it is identical for every estimand
and cell. It therefore collapses to a predetermined replicate count rather
than measuring Monte Carlo difficulty.

V1 produced engineering-only output and was never committed, tagged, locked,
or used for a scientific simulation.

It is superseded by
`TESS_D8A_PROSPECTIVE_RATE_AWARE_PRECISION_CONTRACT_AMENDMENT_V2`.
