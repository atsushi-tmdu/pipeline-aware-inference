# D8-A Numerical Validation

This directory contains the prospective numerical-validation design for the
completed D8-A second-order theory.

The design is locked before any D8-A scientific simulation is run.

The validation has three modules:

1. reference-only threshold bias;
2. evaluation-only finite-\(n\) bias;
3. combined reference/evaluation bias.

The primary family is a three-candidate Gaussian copula with common monotone
marginal transformations. The transformations preserve the winner map while
changing quantile curvature.

The D7 formal result remains FAIL and is not altered by D8-A.
