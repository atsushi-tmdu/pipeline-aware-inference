# D7 Full Scientific Closeout Package

This package freezes the formal D7 continuous maximum-trigger scientific result.

- Formal status: FAIL
- Fatal implementation checks: all PASS
- Scientific simulation repeated after result: NO
- Locked criteria changed: NO
- Post-hoc convergence audit: exploratory and nonadjudicative

Start with:

1. `D7_FINAL_ADJUDICATION.md`
2. `D7_POSTHOC_CONVERGENCE_AUDIT.md`
3. `D7_FULL_FAILURE_DIAGNOSIS.txt`
4. `D7_VALIDATION_ADJUDICATION.md`
5. `D7_SERIALIZATION_RECOVERY.json`

Raw full-run replication files remain under the ignored
`outputs/full_v1/` directory and are represented here by their SHA-256
inventory rather than duplicated in Git.
