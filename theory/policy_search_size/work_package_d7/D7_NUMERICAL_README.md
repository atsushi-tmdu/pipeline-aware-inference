# D7 Prospective Continuous Scientific Protocol

This directory extension defines the prospective D7 continuous
maximum-trigger scientific validation design.

The design contains:

- 72 regular main cells and 144,000 outer replications;
- 18 complete-replication bootstrap cells;
- two strict trigger orderings;
- eight nonadjudicative near-coincidence cells;
- one nonadjudicative exact-coincidence cell.

The numerical design remains a draft until a separate immutable lock manifest
and annotated lock tag are created. No scientific simulation has been run.

The pre-existing D7 theory checkpoint files are intentionally not modified.
